STM32F103C8T6 智能小车三模式整合版
=================================

一、串口 / HC-05
PA9  -> HC-05 RXD
PA10 <- HC-05 TXD
波特率：9600

模式命令：
1 = 停止模式（上电默认）
2 = 蓝牙手动模式
3 = 自动避障模式

蓝牙手动模式（只有模式2有效）：
w = 前进
a = 左转
d = 右转
s = 后退
0 = 停止

二、LED
红灯：3.3V -> 1k电阻 -> LED正极(长脚) -> LED负极(短脚) -> PC15
绿灯：3.3V -> 1k电阻 -> LED正极(长脚) -> LED负极(短脚) -> PB9

注意：LED一定要串联限流电阻，建议1k欧姆。
因为正极接3.3V、负极接GPIO，所以GPIO低电平时灯亮，高电平时灯灭。

状态：
模式1：红灯灭、绿灯灭
模式2：绿灯闪烁（0.5秒亮 / 0.5秒灭），红灯灭
模式3：红灯闪烁（0.5秒亮 / 0.5秒灭），绿灯灭

三、舵机
舵机信号 PB1。
上电默认模式1时不初始化舵机PWM，因此不会主动发送舵机转动命令。
只有收到数字3进入自动避障模式后，才初始化舵机并转到正前方。

四、自动避障逻辑
前方 >= 15cm：前进
前方 < 15cm：停车 -> 看右边
右边可走：原地右转约700ms
右边不可走：看左边
左边可走：原地左转约700ms
前/右/左都不可走：后退500ms，然后重新判断
